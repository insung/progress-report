시나리오 요청문은 구현 세션이 작성하고 handoff에 보존한다. 워크트리 없음·하나·여러 개·미확인, 작업 위치 구분, 자동 검사 일부 통과·사용자 확인 대기를 포함한다. 실행자에게 기대 결과를 전달하지 않는다. 스킬 구조 검사는 출력 행동 검증을 대체하지 않는다. unit test 대상인 실행 코드가 없으므로 에이전트 출력 시나리오로 대체한다.
