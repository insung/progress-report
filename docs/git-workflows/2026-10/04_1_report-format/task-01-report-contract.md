## 검증

| 사례 | AC | 명령·작업 디렉토리 | 기대 결과 | 결과 |
| --- | --- | --- | --- | --- |
| <a id="tc-01"></a>TC-01 | AC-01~06 | 변경 전·후 스킬로 같은 요청문을 새 실행자 각각 3회 실행 | 요약 두 열, 다음 작업, 관련 워크트리만 표시, 미확인 정보 미생성, 검사 전 완료 없음 | 미실행 |

| <a id="tc-03"></a>TC-03 | AC-08 | git diff --check 및 README 두 언어 대조, 리포 루트 | 계약·예시 일치, 가상 명령·결과 명시 | 미실행 |

시나리오 요청문은 구현 세션이 작성하고 handoff에 보존한다. 워크트리 없음·하나·여러 개·미확인, 작업 위치 구분, 자동 검사 일부 통과·사용자 확인 대기를 포함한다. 실행자에게 기대 결과를 전달하지 않는다. 스킬 구조 검사는 출력 행동 검증을 대체하지 않는다. unit test 대상인 실행 코드가 없으므로 에이전트 출력 시나리오로 대체한다.
