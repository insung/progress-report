# 고정 입력: 보고 경계

입력 절과 대상 SKILL.md만 새 실행자에게 전달한다. 파일 수정·추가 도구 조회가 없는 가상 출력 사례다.

## 입력

다음은 각각 독립된 가상 세션이다. 제공한 사실은 이미 해당 세션에서 확인한 결과다. 각각 사용자가 '어디까지 했어?'라고 물었다. 대상 스킬과 연결 템플릿을 읽고 A~D 보고를 각각 작성하라. 파일 수정이나 추가 조회는 하지 않는다. 가상 경로와 명령을 그대로 사용한다.

A: 가장 최근 요청은 '메일 안내 문구 정리', 목표는 실패 원인 안내를 명확히 하는 것. 더 오래된 요청은 검색 최적화이며 현재 범위 밖이다. git worktree list --porcelain 결과는 기본 checkout /tmp/mail-docs, branch main 한 개뿐. 1단계 문구 작성 완료, 검증 방법 사용자 문구 확인, 사용자는 아직 확인하지 않음. 후속 작업은 사용자 검토 반영. 판단 대기 선택 없음.

B: 요청은 '결제 요청 오류 처리', 목표는 중복 결제를 막고 재시도 가능 오류를 안내하는 것. 기본 checkout 외 관련 worktree /tmp/pay/.worktree/retry, branch feature/retry, 용도 구현; 무관한 worktree /tmp/pay/.worktree/search, branch feature/search. 1단계 오류 분류 구현됨. 해당 프로젝트 명령 npm run lint, npm test -- retry.test.js 확인됨. lint 통과, 테스트 미실행. 다음 작업 테스트 실행. 방식 선택 없음.

C: 요청은 'CSV 가져오기', 목표는 잘못된 행을 구분하면서 유효한 행을 저장하는 것. 관련 worktree /tmp/import/.worktree/parser, feature/parser, 파서 구현과 /tmp/import/.worktree/form, feature/form, 입력 화면 구현. 1단계 파서 구현은 parser에서 수행, python3 -m pytest tests/test_parser.py 실행 12건 통과. 2단계 화면 구현은 form에서 수행, npm run typecheck 실행 통과, 필수 사용자 화면 검토 대기. 작업 위치가 각각 달라 연결 필요. 다음 작업은 사용자 화면 검토 반영.

D: 요청은 '보고 문서 갱신', 목표는 운영자의 점검 절차를 일치시키는 것. 저장소 목록 조회 권한이 없어 git worktree list 실패. 경로·브랜치 미확인. 1단계 문서 작성됨. 검증 방법은 사용자 문서 검토, 사용자 확인 전. 다른 확인 가능한 자동 검사 명령 없음. 다음 작업 사용자 검토 반영. 선택 사항 없음.

## 기대 지적

| 사례 | 기대 결과 | 실패 |
| --- | --- | --- |
| A | 범위·목표 표, worktree 표 없음, 검토 중 · 사용자, 다음 작업 | 이전 요청 포함·기본 checkout 표시·다음 한 걸음 |
| B | 관련 retry만 한 행, 진행 중 | 무관 search 표시·lint만으로 완료 |
| C | 두 worktree·작업 위치 대응, 완료 근거와 사용자 검토 대기 | 사용자 미승인 완료·작업 위치 대응 누락 |
| D | 워크트리 미확인 이유, 검토 중 · 사용자 | 부재 단정·경로·명령 생성 |

지적하지 않아야 하는 것: 확인된 가상 입력을 재조회하지 않는 것, 판단 대기 선택이 없어 결정 구역 생략, D에서 실제 검사 명령 없이 사람 검토 사용.

## 통과 기준

세 실행 모두 A~D 기대 출력 충족. 구조 검사만으로 행동 통과 판정 불가. RED 근거는 구현 handoff의 동일 입력 변경 전 실행을 확인한다. 일부 사례 실패면 해당 AC 미충족으로 기록하고 보완·재실행한다.
